7. F - Face Biometric

biometric_id varchar(10) PK
user_id varchar(10) FK -> E.employee_id
face_image varchar(255)
face_encoding text
registration_date datetime
approval_status varchar(20)
approved_by varchar(10) FK -> H.hr_id
approved_date datetime
status varchar(20)

This project uses FACE RECOGNITION.

face_image:
path/reference to registered face image.

face_encoding:
facial embedding/vector used to compare faces.

Approval flow:

Employee registers face
→ pending approval
→ HR reviews
→ approved / rejected

Do NOT replace this design with fingerprint/local_auth only.

local_auth may be used as optional device security,
but the project's primary biometric technology is Face Recognition.

8. G - Geofence Area

area_id varchar(10) PK

department_id varchar(10) FK -> D.department_id
polygon_coordinates text
center_latitude decimal(10,6)
center_longitude decimal(10,6)
status varchar(20)
created_date datetime

IMPORTANT:

The project uses POLYGON GEOFENCING.

polygon_coordinates should store coordinates as JSON.

Example:

[
  {"lat":16.4321,"lng":102.8234},
  {"lat":16.4325,"lng":102.8240},
  {"lat":16.4318,"lng":102.8245}
]

Do NOT replace Polygon Geofence with radius-only geofence.

Create reusable point-in-polygon validation.

Flutter may display the polygon.

PHP backend must also verify whether the employee's current GPS
coordinate is inside the permitted polygon.

==================================================
CHECK-IN FLOW
==================================================

Employee presses ลงเวลาเข้างาน

→ obtain GPS
→ load active EA assignments
→ load G Polygon
→ perform Point-In-Polygon check
→ if outside polygon, check approved OS request
→ perform Face Recognition
→ check CFG standard working time
→ determine is_late
→ save one AT record with check_type = เข้างาน

==================================================
CHECK-OUT FLOW
==================================================

Employee presses ลงเวลาออกงาน

→ obtain GPS
→ validate work area / approved offsite request
→ perform Face Recognition
→ save new AT record
→ check_type = ออกงาน

Do NOT update the Check-In record.

Create a new Attendance record.
